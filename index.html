B.Tech Main ProjectIN PROGRESS

Intelligent CCTV Surveillance Using Human Activity Recognition

I’m developing an AI-powered surveillance system that combines YOLO-based object detection, ByteTrack / DeepSORT multi-object tracking and human activity recognition. It aims to identify activities such as walking, running, loitering and possible falls in real-time video, flag suspicious activity and generate alerts — reducing dependence on continuous manual monitoring.

K-DISC · Block Innovation Project

Scarecrow — Sound-Based Bird Deterrent System

A sound-based bird deterrent concept for protecting Pokkali paddy crops. The proposed prototype uses an Arduino-based control unit to play distress calls at randomized intervals, aiming to reduce bird habituation. The project follows field visits and farmer interactions in the Vypin Block Panchayath area.
